# Ledger Balance (Java Version)

This project is a tool for managing and calculating ledger balances, implemented in Java.

## Features

- Track financial transactions
- Calculate balances
- Generate reports

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/rommelskii/ledger-balance.git
    ```
2. Navigate to the project directory:
    ```bash
    cd ledger-balance
    ```
3. Build the project using Maven:
    ```bash
    mvn clean install
    ```

## Usage

Run the application:
```bash
java -jar target/ledger-balance.jar
```
